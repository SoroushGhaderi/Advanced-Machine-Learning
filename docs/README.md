# Project documentation

This folder contains the course-level documents that support the notebook
sequence. Keep folder-specific guidance beside its content: `data/README.md`
documents the dataset, `concepts/README.md` maps the lesson notes, and
`assets/README.md` documents optional local visuals.

- [Course details](COURSE_DETAILS.md) — modules 00–02 and their video lessons.
- [Notebook catalog](NOTEBOOK_CATALOG.md) — purpose and progression of all notebooks.
- [Capstone rubric](CAPSTONE_RUBRIC.md) — assessment criteria and acceptance gates.
- [Validation report](VALIDATION_REPORT.md) — execution and reproducibility evidence.
- [Project context](../CONTEXT.md) — canonical glossary and evaluation contract.
